# IoT-Based-Bluetooth-RC-Car
## 📌 Description

This project is an Arduino-based Bluetooth-controlled RC car designed for wireless smartphone operation. It uses an HC-05 Bluetooth module to receive movement commands and an L298N motor driver to control two DC motors.

The car can move forward, backward, left, right, and stop based on Bluetooth commands. A PIR motion sensor is integrated to detect motion, while a buzzer provides an alert and stops the car when motion is detected.

### 🔧 Technologies & Components

- Arduino Uno
- HC-05 Bluetooth Module
- L298N Motor Driver
- PIR Motion Sensor
- DC Motors
- Buzzer
- Arduino C/C++

This project demonstrates the integration of embedded systems, wireless communication, motor control, and sensor-based automation in a simple IoT-based smart vehicle.
